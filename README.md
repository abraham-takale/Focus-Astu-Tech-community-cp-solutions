# Focus ASTU Tech Community | CP Solutions

My Python solutions to competitive programming problems, solved while practicing with the **Focus ASTU Tech Community** at Adama Science and Technology University (ASTU).

## Purpose

- Practice algorithmic problem-solving and build strong programming fundamentals
- Keep a organized record of problems I've solved, grouped by topic
- Share solutions that other students can learn from

## Repository Structure

| Folder | Topics Covered |
|--------|----------------|
| `Arithmetic and pattern/` | Math-based problems, number properties, pattern printing |
| `Array/` | Array traversal, counting, grouping, and manipulation |
| `Hash_Maps/` | Dictionaries, frequency counting, lookups |
| `Matrix/` | 2D arrays, grid traversal, matrix operations |

## Tech

- **Language:** Python 3
- **Platform:** Codeforces and community practice sets

## How to Run a Solution

```bash
git clone https://github.com/abraham-takale/Focus-Astu-Tech-community-cp-solutions.git
cd Focus-Astu-Tech-community-cp-solutions
python "Array/Team Olympiad.py"
```

Most solutions read from standard input, so type the input after running or use:

```bash
python "Array/Team Olympiad.py" < input.txt
```

## Approach

For each problem I try to:
1. Understand the problem and work through small examples by hand
2. Choose a suitable data structure (list, dictionary, set, matrix)
3. Check time complexity against the constraints
4. Test with edge cases before submitting

## Note

Try the problems yourself first. Use these solutions to compare approaches, not to skip the learning.
